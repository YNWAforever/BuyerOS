Choose PAS, AIDA, BAB or direct framing to fit the objective. Return outreach_preparation with summary, framework, unknowns and messages containing subject, body, rationale, evidence and suggested_day. Suggested days are advice, never a schedule. All output languages follow the selected en or zh-HK preference. Preserve product/legal names and citations accurately.

Use drafts.prepare only as a proposal through the native draft owner. The skill cannot send, schedule, approve or unsuppress. Native draft references record exact revisions. Recheck source eligibility and draft version at save; a concurrent edit keeps the proposed text available for review and rejects stale application. Completion is a validated, persisted preparation revision with canonical readback, not a claim that outreach was delivered.
