# Prepare a follow-up
The zero-call core route supports nurture by quoting the exact selected authorized context, with prior meetings, agreed actions and dates explicitly unknown. Post-meeting, post-demo, post-proposal and recovery require reviewed grounded model sections with verified interaction facts; the core route returns Needs input naming the scenario instead of saving generic outreach as completed follow-up. Neither route may infer agreement from a research report.
Core preparation authors evidence-grounded messages only. Formal follow-up creation additionally requires the selected interaction output to link one current native parent draft; no parent or prior interaction is invented. Suggested days never create scheduling or delivery intents.

Consume FollowupArguments, including interaction_ref and one explicit scenario: post_meeting, post_demo, post_proposal, recovery or nurture. Read only the selected interaction and project evidence. Ask for missing agreed next steps and offer context; never infer prior conversations from sibling transcripts.

For post-meeting, recap the specific discussion and agreed action. For post-demo, connect demonstrated capabilities to stated needs. For post-proposal, answer outstanding scope or commercial questions using verified terms. Recovery acknowledges silence without guilt or tracking claims. Nurture adds useful professional information without manufactured urgency. Produce one to six messages appropriate to the supplied context, rather than inventing facts to fill a fixed sequence.

Return followup_preparation with scenario, interaction_ref, summary, unknowns and evidence-grounded messages (subject, body, rationale, suggested_day). Each adds new value and has one clear next step. Suggested cadence is reviewable advice only; no mail, phone, SMS or social dispatch is authorised.

drafts.prepare hands a proposal to existing native recipient/policy/version review. It cannot create an approval, change suppression or schedule sending. Preserve the selected interaction in citations. Save/readback the preparation revision; a stale native draft update is rejected without discarding the proposal.
