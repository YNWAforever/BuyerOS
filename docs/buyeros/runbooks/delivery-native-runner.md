## Native attempt and transaction boundaries

1. The actual native worker closes its initial runtime/control guard transaction.
2. `submit_delivery_claimed` validates an exact private `DeliverySelection`: current
   reviewed delivery budget authority, independently reviewed retained reconciliation
   authority, identical workspace/provider/account/scope/contract, both paid flags.
3. A fresh restricted worker tenant transaction checks current immutable approval,
   policy, recipient, actor and owner/generation/epoch; it commits the initial claim.
4. The pure local factory receives only `PreparedDelivery` from server resolution.
   Its independent delivery adapter must estimate exact positive USD Money within
   the original reviewed upper bound. Client text and common provider capability
   cannot substitute for this binding.
5. Another fresh tenant transaction rechecks the current permissions and original
   hold and commits a permanent unknown POST permit. The transaction closes.
6. Exactly one `adapter.submit(original_intent)` awaits outside all DB transactions.
   Tests use an independent connection to read committed unknown/unknown_acceptance
   and acquire message/control/outbox locks NOWAIT during that await.
7. A separate retained-authority tenant transaction saves a typed original response.
   New-admission role/flag/lease revocation cannot erase a received acceptance.
8. The native receipt is finalized under a fresh worker fence as reconciliation.
   A late invalid fence yields stale while preserving the already saved reference.

Accepted is not delivered, a signed webhook, a settled cost or no-charge proof.
Unknown, rejected, cancellation, crash, malformed response and failed DB receipt
commit never authorize a second permit/POST, a new intent key or releasing a hold.
If an accepted response cannot be committed its original permanent unknown marker
remains and needs independent reconciliation; this runner never blindly resends.

`selected_delivery_runtime` returns None. Selecting a real provider/account/sender,
building its reviewed HTTP factory and status reconciliation, settling verified
economics, admitting through the public route, and completing the separate C61-30
real recipient/readback gate remain open work. Existing closed native behavior is
